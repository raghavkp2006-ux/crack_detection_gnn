# Dataset provenance notes

The supplied TITS folder has five sensor groups (AIGLE_RN, ESAR, LCMS, LRIS, TEMPEST2), 269 source image files and 66 annotated native masks, as verified directly in `tits_manifest.json`. It has no supplied train/test subdirectories. All 66 annotated pairs, including one empty GT, are fixed before training as the confirmation cohort. Eight source/mask dimension differences are recorded. Grayscale inputs are promoted to three channels; no source files are modified.

The folder naming is consistent with the Amhaz/Chambon pavement benchmark (this identification is an inference from the sensor names and local layout). The author's [publication record](https://cv.hal.science/sylvie-chambon) confirms Rabih Amhaz, Sylvie Chambon, Jérôme Idier and Vincent Baltazart, “Automatic Crack Detection on Two-Dimensional Pavement Images: An Algorithm Based on Minimal Path Selection,” IEEE Transactions on Intelligent Transportation Systems 17(10), 2718–2729 (2016), DOI 10.1109/TITS.2015.2477675. The original IRIT dataset page could not be fetched by the web tool; local availability and counts do not depend on that page.

DeepCrack is the distinct dataset published with Liu et al.'s 2019 Neurocomputing paper, documented in the [authors' dataset repository](https://github.com/yhlleo/DeepCrack). The provided TITS cohort has no byte-identical source images among the 300 DeepCrack training-source images. Byte matching does not rule out resized/cropped copies from an underlying shared source; this is not claimed to be a complete cross-corpus source-identity audit.

The historical DeepCrack source-ID rule (remove trailing -digits) flags 39/45 validation images (86.7%) with a source ID also in the fixed 210-image training split, and 19/237 original test-folder images (8.0%) overlapping training-folder source IDs. These are pre-existing provenance metadata, not newly evaluated test evidence. Frozen membership is retained as requested. Training-seed SD is not an estimate of source-independent image sampling uncertainty.

The repository also contains earlier TITS fine-tuning/evaluation workflows and artifacts. This task is a once-only locked zero-shot comparison of DeepCrack-trained checkpoints; it is not claimed to be the first project-wide use of TITS. No TITS-finetuned checkpoint or earlier TITS score is used for selection in this study.
